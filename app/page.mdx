# moscovium-mc

<img src="/prof_pic.jpg" alt="moscovium-mc" width="128" height="128" className="rounded-full" />

I'm a Full Stack Developer and Security Researcher with over 10 years of hands-on experience spanning modern web development, offensive security, and independent security research. My work sits at the intersection of building scalable applications and developing practical tools for penetration testing, OSINT, and security automation.

On the web development side, I specialize in designing and implementing end-to-end applications, from responsive front-end interfaces to back-end services. I'm proficient in TypeScript, Go, Python, Next.js, Postgres, MySQL, with experience deploying and maintaining applications on platforms such as Netlify and Vercel. I prioritize clean architecture, maintainable codebases, and friendly workflows.

In security research, my focus is on offensive security and tool development. I primarily work with Python and Bash to create penetration testing utilities, OSINT reconnaissance tools, and automated security assessment frameworks. My work includes credential exposure analysis, Cloudflare and WAF reconnaissance, vulnerability research, exploit development and building scalable tooling for real-world security assessments. I maintain and contribute to multiple open-source security tools and actively engage with the infosec community.
